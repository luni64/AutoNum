# Release Notes V2.4.0 (für Ahnenforschung)

Diese Version bringt einen lang gewünschten Wunsch aus der Praxis: Die Personen lassen sich jetzt wahlweise von der vordersten Reihe aus durchnummerieren. Auf vielen alten Gruppenfotos — Schulklassen, Vereine, Hochzeitsgesellschaften — ist genau das die Reihenfolge, in der die Namen überliefert sind.

## Neue Funktionen

- **Nummerierung wahlweise von unten nach oben**
  - Bisher wurde immer mit der obersten Reihe begonnen. Neu kann die Zählung auch bei der **untersten (vordersten) Reihe** starten. Innerhalb einer Reihe wird weiterhin von links nach rechts gezählt.
  - Als **Standard für neue Bilder**: Datei → Einstellungen → Erkennung → „Mit der untersten Reihe beginnen".
  - **Pro Bild** umschaltbar im Formatieren-Dialog der Nummern (rechte Spalte): Die Nummern werden sofort neu vergeben, und die Namensliste zieht direkt nach.
  - Die Reihentrenner in der Namensliste passen sich an: Zählt man von unten, heißt die vorderste Reihe „Reihe 1" — die Liste bleibt also von 1 bis n durchgehend lesbar, in der Vorschau, im JPG und im PDF.
  - Die gewählte Richtung wird **im Bild mitgespeichert**. Ein später wieder geöffnetes Bild behält seine Nummerierung, auch wenn der App-Standard inzwischen ein anderer ist.

## Hinweise für bestehende Dateien

- Bereits gespeicherte Bilder bleiben unverändert bei der bisherigen Zählung von oben nach unten — auch dann, wenn Sie später Nummern verschieben oder ergänzen. Die neue Richtung gilt nur dort, wo Sie sie ausdrücklich einschalten.
